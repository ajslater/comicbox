# Reading List Source

_One place a list came from. A source with a key and no revision is a pointer:
the list is known to exist there and was not fetched from it._

## Properties

- <a id="properties/kind"></a>**`kind`** _(string)_: metron-list, metron-arc,
  comicvine-arc, json-cbl, catalog, url, file or tags.
- <a id="properties/key"></a>**`key`** _(string)_
- <a id="properties/url"></a>**`url`** _(string)_
- <a id="properties/revision"></a>**`revision`** _(string)_
- <a id="properties/curator"></a>**`curator`** _(string)_
- <a id="properties/curator_url"></a>**`curator_url`** _(string)_
